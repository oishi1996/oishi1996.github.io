# oishi1996.github.io

このリポジトリは、Hugo と Blowfish テーマを使った個人サイトです。

## サイト URL

<https://oishi1996.github.io/>

## 現在のメニュー構成

- まとめ
- 略歴
- 発表
- ブログ

## 使い方

1. `config/_default/hugo.toml` の `baseURL` を確認
2. 日本語サイトのメニュー設定は `config/_default/menus.ja.toml`
3. コンテンツは `content/` 以下に配置
